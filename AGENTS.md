# Работа с KinoPulse

Перед изменениями прочитайте README.md, PROJECT_STATUS.md и docs/ARCHITECTURE.md.
Цель: бесплатный Android-клиент с открытым кодом, без обязательного собственного backend.
Обсуждение с владельцем и документация — на русском языке.

## Сборка и проверки

- JDK 17 или 21; Android SDK Platform 35, Build Tools 34.0.0; Gradle Wrapper 8.9.
- SDK задаётся через ANDROID_HOME либо локальный, исключённый из Git local.properties.
- Windows: `gradlew.bat assembleDebug lintDebug testDebugUnitTest`.
- Linux/macOS: `./gradlew assembleDebug lintDebug testDebugUnitTest`.
- APK: app/build/outputs/apk/debug/app-debug.apk.
- Для изменений кода выполняйте соответствующие проверки; для документации достаточно
  проверки ссылок, состава файлов и diff. Не выдавайте старый результат сборки за новый.

## Ограничения и соглашения

- Не копируйте код, бренд и ресурсы Seena. Не запускайте неизвестные установщики.
- Сохраняйте явную маркировку демо-данных и атрибуцию тестовых видео.
- Интеграции внешних источников основывайте на доступной документации и разрешённом доступе.
- Не добавляйте ключи, пароли, подписи APK, local.properties, SDK, кеши и сборки в Git.
- Не отключайте проверку HTTPS-сертификатов ради сборки или проигрывания.
- Сохраняйте совместимость данных избранного/прогресса; при изменении формата нужна миграция.
- Каждая задача — отдельная ветка и понятное описание проверки; избегайте несвязанных изменений.
- Отмечайте фактический результат и ограничения в документации проекта.

Текущий этап ограничен подготовкой репозитория. Участников, облачную среду, CI,
публикацию приложения и публичную видимость репозитория не настраивать без нового задания.
