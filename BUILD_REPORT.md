# KinoPulse 0.2.0-demo — результат разработки

Дата проверки — 10 ноября 2026 года.

## Готово

Собран устанавливаемый debug APK для Android 8.0 и новее.
Проверена подпись APK Signature Scheme v2.
Восстановлен официальный Gradle Wrapper 8.9.
Избранное и прогресс сохраняются через Preferences DataStore.
Прогресс разделён по фильмам, сезонам и сериям.
Кнопки закрытия и системного возврата сохраняют текущую позицию.
При уходе в фон плеер ставится на паузу и сохраняет позицию.
Есть фильтр избранного, повторная попытка после ошибки видео и иконка приложения.
Убраны дублирующие варианты качества и автомобильные ролики с неподтверждёнными правами.
Недоступные Google Storage ссылки заменены на доступные тестовые потоки.
Для Sintel и Big Buck Bunny используются явно обозначенные трейлеры.
Код проекта выпущен под выбранной для этого этапа лицензией MIT.

## Проверки

assembleDebug — успешно.
testDebugUnitTest — 3 теста, 0 ошибок, 0 пропусков.
Тесты проверяют раздельные ключи прогресса серий и сезонов, общую позицию
для вариантов одного эпизода и одного фильма.
lintDebug — 0 ошибок, 33 предупреждения.
27 предупреждений касаются обновлений зависимостей, 3 — версии Android Gradle Plugin,
3 — устаревших сторонних проверок Lint. В журнале также есть предупреждения
совместимости API анализатора Kotlin. Полнота этих сторонних проверок ограничена.
Подпись APK проверена утилитой apksigner.
HTTP HEAD для трёх новых потоков вернул 200, серверы заявляют поддержку Range.
Это не заменяет проверку фактического воспроизведения на устройстве.

## Проверка на устройстве — 10 ноября 2026 года

APK установлен на Lenovo TB336FU с Android 15.
Главный экран и карточки открылись, изображение видеоплеера проверено снимком экрана.
Трейлер Sintel воспроизводится. После системной кнопки «Назад» и принудительного
завершения процесса восстановилась позиция 20 секунд. Продолжение открыло ролик
с сохранённого места, затем наблюдалась позиция 28 секунд.
Избранное сохранилось после полного перезапуска. Фильтр оставил выбранный фильм.
Экранная кнопка закрытия также сохраняет текущую позицию.
Проверены обе серии демонстрационной подборки. В DataStore раздельно сохранены
S1E1 — 5733 мс и S1E2 — 6246 мс. Вторая серия не получила позицию отдельного фильма
Sintel — 52208 мс. В фоне в двух замерах с интервалом 6 секунд позиция не изменилась.
Записей об авариях AndroidRuntime за проверку не обнаружено.

Не проверены обрыв сети, все модели устройств и полное воспроизведение Tears of Steel.
Звуковая дорожка инструментально не прослушивалась.
В интерфейсе остаётся позиция просмотренного до конца трейлера в разделе продолжения.
Улучшение завершённых просмотров и визуальная доработка каталога остаются следующими задачами.
На устройстве оставлены приложение, один тестовый фильм в избранном и тестовая история.

## Ограничения этапа

Это демонстрационная версия, каталог реальных новинок и киноисточники не подключены.
Работающий собственный сервер не требуется. Видео требует доступа к внешним серверам.
Карточки имеют градиентные обложки. Демо-сериал является условной подборкой трейлеров.
Принудительное завершение процесса может потерять несколько последних секунд позиции.
Подпись debug предназначена для тестирования, а не для публикации в магазине.

## Сборка

Требуются JDK 17 или 21 и Android SDK 35.
Команда Windows — `gradlew.bat assembleDebug lintDebug testDebugUnitTest`.
В этой среде прямые HTTPS-запросы Java к Google Maven завершались ошибкой TLS.
Для сборки использован временный локальный кеш, получающий официальные зависимости
через curl с проверкой HTTPS-сертификатов. Эти настройки не включены в проект.
Стандартные репозитории Google Maven и Maven Central сохранены.
