# KinoPulse

**KinoPulse** — открытый Android-проект для удобного просмотра видео, организации избранного и продолжения просмотра с сохранённого места. Дальнейшая цель — просмотр и скачивание фильмов и сериалов из доступных на законных основаниях источников **без необходимости развёртывать собственный backend-сервер**.

> **Статус:** ранняя демонстрационная версия `0.2.0-demo`. Репозиторий содержит исходный код и инструкции сборки, но пока не готовый публичный релиз полноценного онлайн-кинотеатра.

## Что уже работает — ветка `main`

- Android-приложение на **Kotlin, Jetpack Compose и Material 3**, Android **8.0+**.
- Встроенный демонстрационный каталог с поиском и фильтрами.
- Просмотр тестовых видеоматериалов через **Media3 / ExoPlayer**.
- Избранное и история прогресса, сохраняемые **локально в Preferences DataStore**.
- Независимые позиции просмотра для фильмов и отдельных серий; продолжение с сохранённого места.
- Сохранение позиции при закрытии плеера и уходе приложения в фон.
- Пауза в фоне, сообщение об ошибке воспроизведения и повторная попытка.

**Подтверждённая проверка от 10 ноября 2026 года:** сборка `assembleDebug`, три модульных теста и `lintDebug` (без ошибок, с предупреждениями). Демо также проверялось на Android-планшете. Подробности и ограничения — в [BUILD_REPORT.md](BUILD_REPORT.md).

## Экспериментальная ветка

В [`feature/open-movies-and-direct-links`](../../tree/feature/open-movies-and-direct-links) находятся **ещё не объединённые с `main`** изменения:

- отдельный источник открытых фильмов Blender Foundation через Wikimedia Commons;
- добавление пользователем прямых **HTTPS-видеоссылок**;
- локальное сохранение этих ссылок в DataStore;
- поддержка модулей Media3 для HLS/DASH.

Эта ветка **не прошла подтверждённую сборку и проверку на реальном устройстве**. Её возможности не следует считать готовым пользовательским релизом.

## Что планируется

- Подключение документированных источников видео с проверкой условий использования и прав на контент.
- Поддержка скачивания доступных для этого видеоматериалов и управления загрузками.
- Улучшенный поиск, каталог, обработка недоступных потоков и кеширование.
- Доработка интерфейса для телефонов и планшетов.
- В перспективе — клиент для Windows.

**Пока не реализованы в `main`:** скачивание видео, каталог актуальных фильмов из внешних сервисов, аккаунты, синхронизация между устройствами и Windows-приложение. Это проект в разработке.

## Архитектура: без собственного сервера

Приоритет проекта — **local-first-подход**: избранное, прогресс и настройки хранятся на устройстве, отдельные пользовательские аккаунты и собственный backend для базовых функций не нужны.

При этом для **онлайн-воспроизведения** нужен интернет: видео загружается с внешних серверов правообладателей или других разрешённых источников. «Без собственного сервера» не означает работу всего видео офлайн и не отменяет инфраструктуру внешних поставщиков.

**Технологии:** Kotlin · Jetpack Compose · Material 3 · Media3/ExoPlayer · Coroutines/StateFlow · Preferences DataStore · Gradle.

Подробная структура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка

Понадобятся **JDK 17 или 21**, **Android SDK Platform 35** и **Build Tools 34.0.0**. Путь к SDK задаётся в `local.properties` (через `sdk.dir`) или переменную окружения `ANDROID_HOME`.

На Windows:

```powershell
.\gradlew.bat assembleDebug lintDebug testDebugUnitTest
```

На Linux / macOS:

```bash
./gradlew assembleDebug lintDebug testDebugUnitTest
```

Debug APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`. На первой сборке потребуется доступ к Google Maven и Maven Central. Debug-подпись **не предназначена для распространения релизов**.
