# Архитектура

## Текущая реализация

Один Android-модуль `app`: Kotlin, Jetpack Compose/Material 3, Media3 ExoPlayer,
Preferences DataStore, coroutines и StateFlow. Серверная часть отсутствует.

Основные файлы находятся в `app/src/main/java/ru/openstream/kinopulse/`:

| Файл | Назначение |
| --- | --- |
| MainActivity.kt | Точка входа и подключение интерфейса |
| domain/model/MediaModels.kt | Модели каталога, сезонов, серий и потоков |
| domain/model/PlaybackKey.kt | Ключ прогресса фильма либо сезона/серии |
| domain/source/CatalogSourceAdapter.kt | Возможности и контракт адаптера |
| data/demo/LocalDemoCatalogAdapter.kt | Встроенный демонстрационный источник |
| ui/CatalogViewModel.kt | Загрузка каталога, фильтрация, избранное, прогресс |
| ui/screens/HomeScreen.kt | Главная и продолжение просмотра |
| ui/screens/DetailsScreen.kt | Карточка и выбор серии/потока |
| ui/screens/PlayerDialog.kt | Плеер, жизненный цикл, ошибки и сохранение позиции |

Контракт адаптера содержит `getRecentFeed`, `search`, `getDetails`.
Варианты потоков сейчас вложены в MediaItem/эпизоды; отдельного метода получения потоков нет.
ViewModel напрямую создаёт LocalDemoCatalogAdapter. Поиск и фильтрация UI локальные.
При сетевой интеграции потребуется внедрение адаптера и работа с ошибками/загрузкой.

## Данные на устройстве

Preferences DataStore `catalog`, строковый ключ `state`, JSON с `favorites` и `progress`.
Прогресс содержит mediaId, variantId, подписи и positionMs. Ключ различает сезоны/серии;
смена качества одного видео не должна создавать независимый прогресс.
Сам каталог не записывается в DataStore: он встроен в исходники и загружается заново.

## Воспроизведение

Media3 получает прямые ссылки на внешние тестовые видео. Интернет нужен для видео,
но не для демонстрационных карточек. Плеер сохраняет позицию каждые 5 секунд,
при закрытии и уходе в фон. В фоне воспроизведение приостанавливается.
После принудительного завершения процесса возможна потеря последних секунд.

## Направление расширения

Добавить репозиторий каталога между адаптерами и UI, дисковый кеш, фоновые обновления,
пагинацию и устойчивые идентификаторы источников. До выбора сетевого API не фиксировать
конкретную библиотеку базы данных или формат секретов. Наличие API каталога само по себе
не означает наличие разрешённых прямых потоков. Встроенный общий секрет можно извлечь из APK.

Облачные средства разработки не являются backend приложения. Windows пока не реализован.
