# Вход в проект для нового участника

## Цель

KinoPulse — бесплатный проект с открытым кодом, вдохновлённый сценарием просмотра Seena.
Приоритет — Android APK; Windows позже. Собственный постоянно работающий сервер
и обязательные платные API нежелательны. Карточки должны показываться сразу при запуске,
при повторном запуске будущий сетевой каталог должен восстанавливаться из кеша.

## С чего начать

Рабочая основа — версия 0.2.0-demo в ветке `main`. Прежде чем изменять код,
изучите уже работающие функции и сохранённый формат пользовательских данных.

Читайте в порядке: README.md → PROJECT_STATUS.md → docs/ARCHITECTURE.md → ROADMAP.md.
BUILD_REPORT.md содержит результаты ранее выполненных проверок и их ограничения.
Отдельные экспериментальные ветки могут содержать непроверенные изменения;
не считайте их частью стабильной демоверсии до сборки и тестирования.

Исходный код — MIT; права на видео отдельные, см. THIRD_PARTY_NOTICES.md.
Сторонние установщики и материалы других приложений не включены в этот репозиторий.

## Как работать вдвоём

1. Согласовать конкретную задачу и ответственного.
2. Создать ветку от актуального main.
3. Внести изменение, проверить его и описать результат.
4. Открыть pull request; второй участник проверяет код и APK.
5. После принятия объединить изменения и обновить состояние/план проекта.

Чаты разных участников не синхронизируют знания автоматически. Решения, которые влияют
на реализацию, сохраняйте здесь или в задачах репозитория. Общие пароли не нужны.

## Сборки, публикация и подпись

Готовые релизные APK и постоянный ключ подписи не хранятся в Git.
При добавлении CI учитывайте проверки сборки, тестов и Lint в Pull Request.
Публикацию приложения и управление релизными ключами согласовывайте с владельцем.
Если подпись нового APK отличается от уже установленной, Android не позволит
обновить приложение поверх предыдущей версии без дополнительных действий.
